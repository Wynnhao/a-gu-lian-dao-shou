# 施工方案：概念轮动（跷跷板）信号 + 周期比值 regime 旁路

> 2026-09-19 · 需求讨论四轮收敛的产物。原始诉求是"个股对冲关系"（A 跌→B 涨→上调 B），
> 经真实数据实证后**形态修正**为概念粒度轮动信号 + 宏观周期先验，本文为最终方案。

## 1. 背景与实证结论（所有数字均为 2026-09-19 用 market.db 全池实测）

| # | 假设 | 实测结果 | 裁决 |
|---|---|---|---|
| 1 | 个股对：A 跌→B 当日涨（近250日条件概率） | 最强对 双汇→沪电 84%（基准52%）、茅台→华工 79% | 现象真实 |
| 2 | 个股对：T+1 可交易口径 | 25 对中仅 4 对 lift>+4pp；**ρ最强的 双汇→沪电 反而 -12pp/-0.45%日均** | **不可交易，否决** |
| 3 | 概念对：T+1 口径（8 组等权收益） | 消费跌→次日AI 63%（基准54%）；全线 +6~9pp 方向一致 | **可交易，采纳** |
| 4 | 概念对：3 日累计 | 厄尔尼诺跌→半导体 +1.82%（68% vs 58%）；消费跌→半导体 +1.74% | 轮动持续数日 |
| 5 | 概念对：动量混杂对照 | 苹果跌→AI 在 AI 自身动量弱时 72%/+1.04%，动量强时 45%/-0.39%；朴素动量基线仅 49% | **信号是增量信息，非动量影子** |
| 6 | 概念相关性稳定性 | 消费↔苹果、消费↔半导体 前后半窗口同负（250日 -0.22~-0.24，60日 -0.47~-0.50） | 关系稳定 |
| 7 | 铜油比/油金比因子 | 系统零数据零因子；akshare 三源（沪铜CU0/布伦特OIL/上海金）均活且新鲜至 09-18 | 可立项，regime 层适配 |

**核心认知**：个股层面"当日跷跷板"是特质性事件、隔日即散；概念层面轮动是持续 1~3 日的
资金流，日频系统追得上。机制本质是**风格/板块轮动**，非"对冲"——代码与文档统一用
「概念轮动」命名，避免误导。

## 2. 总体架构

```
第一层 周期先验（慢，季度级）     第二层 轮动信号（快，日-周级）      执行层（现有，不动）
铜油比/油金比 分位象限     ──→   概念组基础权重先验                 regime 档位上限（满配/半配/避险）
  (M2, regime 旁路)              +                                 kill / 规则16止损 / MDD红线
                                 A组深跌>0.8% → B组接力窗口1-3日     单票上限
                                 (R2, bundle 注入 LLM 上下文)             │
                                     │                                   ▼
                                     └── B 组内用现有 momentum/score 选票 → LLM 决策 → 风控闸门
```

原则：**轮动只做"方向证据 + 软性权重建议"，不做机械下单**；硬风控一概不动；
与生产 momentum profile 的关系是"给 LLM 多一路证据"，由现有决策框架仲裁。

## 3. 批次拆分

### R1 · 概念轮动 walk-forward 回测（gate 批，约 0.5~1d，纯离线）
- 新建 `signals/rotation.py`（研究版）：概念等权收益（close_qfq，组内 ≥6 只有数据才计，
  与本次实测同口径）→ 滚动重估配对白名单 → 触发信号序列。
- **白名单纪律**：每月末重估一次（非每日）；入选需同时满足
  ρ_250d < -0.15 且 前后半窗口同负 且 ρ_60d < -0.20；单对每周最多触发 1 次（触发日成簇去重）。
- 触发规则：A 组日收益 < -0.8% → 目标 B 组未来 3 个交易日为接力窗口。
- 回测：2024-01~2026-09 walk-forward（只用当月可得数据选对），扣双边成本 0.2%，
  对照三条基线：①空仓 ②池内等权 ③**持有最强动量概念**（关键基线，防"轮动=动量"假阳性）。
- **Pass 标准（先定后跑，不许事后挪）**：扣成本后信号腿 vs 基线③ 年化超额 ≥ +5%，
  分年度 3 段中 ≥2 段为正，组合 MDD 不劣于基线③超过 2pp。
- Fail 即归档结题，不进生产——预期管理：样本仅 2.7 年、触发日成簇、56 对里挑头部存在
  多重选择偏差，本批就是为证伪留出口。

### R2 · 概念轮动生产化（R1 pass 后，约 1~2d）
- 新表 `concept_return`（概念日收益，回测与 bundle 同一数据源）+ `concept_rotation`
  （信号事件：trigger 组/目标组/窗口起止/当时 ρ 与历史 lift）。
- pipeline 各节点（盘前/午评/尾盘）注入 bundle 字段：
  `concept_rotation: {trigger: {组, 涨跌幅}, targets: [{组, ρ, 历史lift_1d/3d, 窗口剩余}], note: 软性参考}`
- 权重建议形态：LLM 上下文中标注"B 组接力窗口"，组内选票走现有 momentum/score，
  建议仅在该组候选票的仓位上限内做 ≤+5% 倾斜，不新增杠杆、不绕任何闸门。
- 测试：概念收益幂等/缺失日容忍/白名单稳定性断言；CONSTRAINTS.md 增补对应红线。

### M1 · 宏观比值离线研究（gate 批，约 0.5d，与 R1 可并行）
- 拉沪铜 CU0 / 布伦特 OIL / 上海金全史 → 铜油比、油金比 → 60/250 日滚动分位
  （**禁用绝对水平**，防供给冲击漂移；主力合约换月跳空用分位钝化）。
- 两项检验：①比值分位四分桶 × 池内 8 组未来 20/60 日收益，看象限分辨率；
  ②与 regime 现有四路输入（RSRS/双动量/国债/波动率）做共线性对照——
  **与 000300 动量相关性 > 0.7 即判冗余，fail 不落地**（铜与大盘周期共线是主要风险）。

### M2 · 宏观比值生产化（M1 pass 后，约 1d）
- `data/macro.py` 加 `fetch_commodity`：三源接入，兜底链 + 新鲜度闸门
  （照抄 bond 通道 W-B8 模式：末行早于今日-7 天整体弃用；教训先例：ETF 份额通道
  因源不存在已死，W-B7）。
- 新表 `macro_commodity_ratio`；`risk/regime.py` 加第五路旁路：象限极端（如滞胀）
  时调制档位上限（幅度 ±10pct 内，fail-open 与 regime 本体一致）；bundle 透出周期象限字段。
- 象限→概念组先验映射初版人工定（复苏→半导体/AI/新能源、滞胀→消费/生物医药），
  M1 的分桶结果如足够可改为数据驱动。

### X · 暂缓/否决项（留档）
- 个股粒度机械对子：实证不可交易，否决。
- 尾盘 14:50 盘中口径（A 盘中急跌+B 当日在涨→尾盘提示）：R1 落地后若实盘显示接力
  窗口前置化有价值再评估，届时直接复用白名单。
- 申万行业粒度：market.db 无行业列，需一次性打标 86 只；且池子按题材组构造，
  切行业后部分组仅剩 1~2 只、聚合优势消失。暂缓，概念组先行。
- 真空头对冲（股指期货/融券）：维持 P3 原判，模拟盘边界外。

## 4. 风控红线（进 CONSTRAINTS.md 的部分）
1. 轮动信号是证据与软建议，任何批次不得使其成为绕过 regime/kill/止损的通道。
2. 配对白名单重估频率不得高于每月；任何"每日重算相关性选对"的实现视为过拟合违规。
3. 回测 gate 未 pass 的模块不得接入生产 pipeline；gate 标准先于回测固化的纪律沿用 W-D6。
4. 宏观通道失效必须 fail-open 且 bundle 显式标注"通道缺失"，不得静默伪装成"中性"。

## 6. R1 / M1 结题结果（2026-09-19 实跑，gate 裁决）

> 运行：`.venv/bin/python3 -m signals.rotation` / `-m signals.macro_ratio_research`，
> 退出码 0=pass / 1=fail。判据均为 §3 预注册口径，实跑后未做任何调整。

### 6.1 R1 概念轮动 walk-forward —— FAIL（归档结题，R2 不开工）

- 测试窗 2025-02 起（首个满足 250 日白名单窗口的月份），共 20 个重估月。
- **白名单 1/20 个月非空**：仅 2026-09 检出 消费→苹果、消费→半导体；
  全期仅 2 个信号（2026-09-10 同日触发，窗口 09-11~09-15）。
- 信号腿与动量基线③完全重合（2026-09 动量基线恰好持有 半导体 = 信号目标，已单独
  诊断确认系巧合而非代码缺陷）：年化 52.3% vs 52.3%，超额 +0.00%；三段 0/3 为正；
  MDD 差 0（③项平凡 PASS，两腿重合所致）。
- Gate：① +0.00% < +5% FAIL；② 0/3 FAIL；③ 平凡 PASS → **总 FAIL**。
- **归因**：同日跷跷板现象真实，但"可持续检出"的负相关对在 walk-forward 下几乎不存在——
  全样本负相关集中于最近 ~60 日行情（前半窗 ρ 仅 -0.09~-0.14），"250 日窗+前后半同负
  +ρ_60<-0.20"的稳健判据在 2026-09 之前从未触发。§1 表中 #3/#4 的次日/3 日 edge 属于
  **近期行情特异 + 事后可见**，不构成可部署信号。这正是 walk-forward gate 要拦的东西。
- 再评估条件（必须作为新预注册批次立项，不得微调本批口径重跑——多重检验红线）：
  池内日线历史扩至 >4 年（白名单窗有足够前后半对比）；或出现独立证据表明
  防御↔成长跷跷板已结构化为长期风格制度而非行情段。

### 6.2 M1 宏观比值 —— FAIL（归档结题，M2 不开工）

- 数据：CU0 2010~（4063 行）、布伦特 OIL 2016~、COMEX GC 2016~（黄金取美元同源，
  未用 SGE 规避汇率 caveat），三源交集 2414 天；比值一律 60/250 日滚动分位。
- **检验② 共线性：大幅 PASS**（max|corr| = 0.099 vs 阈 0.7）——铜油比/油金比与
  HS300 动量近乎正交，"铜=大盘周期影子"的冗余担忧实测不成立，信息是增量的。
- **检验① 分辨率：FAIL**（预注册线 |Spearman|>=0.2 且 20/60d 同号）：
  铜油比 fwd20 -0.11 / fwd60 +0.09（跨期反号，分桶非单调，Q0=+12.8% 反而最高）；
  油金比 fwd20 +0.09 / fwd60 -0.12（同样跨期反号）。
- 附表（非 gate）：四象限中"铜油比低/油金比高 → 成长-防御价差 +9.3%"（n=82）与
  "铜油比高/油金比高 → -7.7%"（n=17）方向符合周期叙事，但样本小、整体非单调，
  不足以推翻 gate。
- **归因**：两比值与现有 regime 输入正交（有增量信息），但对"未来 20/60 日 成长vs防御"
  的分辨率低于预注册线——正交但无咬合。
- 再评估条件：换象限定义（叠加库存/利率曲线维度）或 horizon 拉长至季度级
  （与因子本征周期对齐），作为新预注册批次。
