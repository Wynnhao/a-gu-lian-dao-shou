## 内部归档（项目研发过程留档，不供外部阅读）

研发过程文档（Sprint 计划、批次报告、多 agent 审查报告、施工方案、ADR 草案）已统一移到 [`internal/archives/`](internal/archives/)。这些文档记录了项目从立项到 v1.3 的工程迭代过程，含大量内部代号、批次编号、研究判据：

- 适用场景：项目维护者做历史回溯、贡献者理解某些决策的背景
- **不建议**：首次接触项目的人从这里读起——会被 AI 协作术语和内部编号淹没

详细说明见 [`internal/README.md`](internal/README.md)。

## 文档维护原则

- **核心文档**保持简洁、以原理和当前状态为主，不混入历史过程
- **过程文档**集中到 `internal/archives/`，原始 commit 仍可在 git 历史里查
- **更新文档**时同步更新本文档的索引

如发现文档与代码不符，欢迎提 Issue 或 PR。
