## 1. 口径重钉（§3.3 冻结）与实现层钉死

三条预注册重钉（原文见 chan_evidence.py docstring）：

1. 标签流由 chan_causal 前缀重算逐日生成；**历史标签永不回改**（首发确认即锁定）。
2. 三买状态标签：首发确认日锁定「三买持仓态」，出场条件触发（顶分型确认或 20 日
   先到，照 R3 §3.6-8 出场计数）后转「三买结束」；此后同枢再确认按新事件记录。
3. 结构上下文标签逐日更新但只增不改历史：当前笔方向、最近顶/底分型类型与距今
   交易日数、最近中枢 [ZD,ZG] 与现价相对位置（上/内/下）。

实现层钉死 a~j（消歧义、不新增可调参数；全文见模块 docstring），要点：

| 钉死 | 内容 |
|---|---|
| a | 标签行 = warmup 起始日后全部有 bar 交易日，每日期恰一行；R3 测试窗不适用（全史 warmup 后口径）；warmup 资格不足（<120 有效 bar）→ 空流 |
| b | 事件输入 = chan_causal emitted（<5 交易日去重 + warmup，test_start=None），与 R3 生成层同源同实现 |
| c | 出场日 = plan_signal_trade（R3 §3.6-8 冻结实现逐字复用）的出场执行日；状态在出场执行日翻转；数据末未出场 → 持仓保持至末（事件级标注"数据末"） |
| d | 持仓中忽略：新信号确认日 ∈ 既有事件 [首发确认日, 出场执行日) → 不开新事件；确认日 == 出场执行日 → 开新事件（同日先释放后入场，与 R3 组合层次序一致）。此即"同枢再确认按新事件记录"的实现 |
| e | 末根确认的不可交易信号仍开事件（结构状态非持仓，exit=数据末） |
| f | 上下文定义：当前笔方向 = 最近保留分型起的形成笔（底→上/顶→下）；最近分型 = 前缀全部检出分型中确认 bar 最大者（不限成笔端点）；最近中枢 = (last_stroke_idx, start_stroke_idx) 字典序最大者；现价 = 当日收盘（close_qfq） |
| g | 披露①相容 = 同日 ∪ 近距 \|Δ\|≤8（NEAR_SHIFT_BARS，chan_causal 冻结诊断阈值；移位类容差）；消失类 = 终态结构否认该处存在三买 |
| h | 披露②离散字段 = {三买状态, 当前笔方向, 最近分型类型, 中枢相对位置}（"距今 N 日"计数器不计变更） |
| i | 披露④恒等式：\|E_r3\| = 窗口内事件数 + 窗口内持仓中忽略数 |
| j | 样例票确定性选取：最多事件 / 000333（R3 §6.2 点名）/ 中位事件 |

复用资产（全部只读零修改）：chanlib（结构引擎）、chan_causal（前缀重算 + 去重 +
§3.6-8 出场计划 + NEAR_SHIFT_BARS）、chan_data（数据层 + warmup）。

**20日出场 0 例的如实说明**：272 事件中顶分型出场 269、数据末 3、20 日出场 0。机制：
chan_causal 钉死 b 的顶分型出场事件流为"前缀时点检出的**全部**顶分型确认（不限成笔

R3 冻结语义（§3.2 + chan_causal 实现层钉死 b）的既有行为，本批照抄复用、不改判不调参。

## 3. 强制披露四项（如实回填，无阈值 gate）

### 3.1 ① 锁定三买标签 T+20 终态相容率 = **70.22%**

- 全史（warmup 后）：相容 191/272 = **70.22%**，其中同日命中 104 = 38.24%、近距
  （|Δ|≤8 交易日）87 = 31.99%；消失类 81 = **29.78%**。
- 窗口内对照（首发确认 ≥ 2024-07-01）：与全史完全同值（191/272）——本库数据自
  2024-01-02 起、warmup 起始日 2024-07-03 ≥ TEST_START，warmup 已吞没测试窗，
  窗口外事件为 0（数据地平事实，如实注明）。
- **与 R3 Gate2 的对照**（同窗同引擎）：R3 重画率 61.46% = 移位 90 + 消失 87（/288）；
  本批同日命中 104/272 = 38.2% ≈ R3 命中 111/288 = 38.5%；消失类 81/272 = 29.78%
  ≈ R3 消失类 87/288 = 30.2%——两组数字同向印证，差异来自事件集（288 信号 vs
  272 事件，16 个持仓中忽略信号未成事件）。
- **语义解释**：R3 机械版要求"同票同确认日终态仍构成三买"，移位类（末根合并K
  i_end 延长致确认日后移）与消失类一并计为重画 → 61.46% FAIL。证据版语义下移位
  类不是矛盾——形态存在、确认日近距移位，标签锁定首发日即为因果事实；真正与终态
  矛盾的只有消失类 29.78%（终态结构改写后否认该处存在三买）。**这正是本批存在的
  理由：同一现象从"机械 gate 的失败"转为"锁定事件 + 相容率披露"，供 LLM 作为
  带已知噪声水平的软证据消费。**消失类事件票 36 只（top：000333/002008/002129/
  002460/002938/300136 各 4）。
- 诊断补充（非披露项）：事件级出场原因分布——顶分型 269 / 数据末 3（000651 #8
  2026-09-18 末根确认不可交易、300433 #9 2026-09-16、600809 #5 2026-09-17 出场
  规则均不可得）/ 20日 0（见 §1 语义说明）。

### 3.2 ② 标签日变更频率/票 = **0.4302**

- 离散字段口径（钉死 h）：{三买状态, 当前笔方向, 最近分型类型, 中枢相对位置}；
  分母 = 标签行数 − 1；票数 50（均有 ≥2 行）。
- 池聚合 **11580/26919 = 0.4302**；票均值 0.4302 / 中位 0.4378 / min 0.3655 /
  max 0.4824。
- 三买状态单独变更：池 **535/26919 = 0.0199**（票均值同）——上下文标签日均 ~43%
  变更（笔方向翻转/分型更替/中枢位置轮动，属正常结构动态），三买事件标签 ~2%
  日变更（低频、事件驱动）。LLM 消费含义：上下文字段高频轮换、三买状态字段稀疏
  稳定——bundle 摘要（§5）以三买状态为锚、上下文为辅，与此频率结构一致。

### 3.3 ③ 覆盖率 = **50/50**（分母 50 逐字照抄；core 实际 51 只）

### 3.4 ④ 与 R3 机械信号流（288 实发）的关系

- **同源性**：证据事件输入 = chan_causal emitted（前缀重算 + <5 交易日去重 +
  warmup），与 R3 chan_research 生成层同一引擎、同一数据、零改动复用——实跑
  E_r3（emitted 中确认日 ≥ 2024-07-01）= **288，精确复现 R3 实跑数字**。
- **恒等式**（钉死 i）：288 = 窗口内证据事件 272 + 窗口内持仓中忽略 16
  （状态机处理 emitted 全序列，每个信号非忽略即开事件；实跑逐项核对成立）。
- **差异归因**：
  1. 证据版无测试窗（全史 warmup 后）；本库 warmup 起始 2024-07-03 ≥ TEST_START，
     窗口外事件为 0——此项差异在当前数据地平下为空，如实注明；
  2. 16 个持仓中忽略发生在**标签层**（按确认日标签状态，钉死 d）；R3 的同票忽略
     发生在**组合层**（按候选入场日 ∈ [入场, 出场)，§3.3 组合构造）——两口径的
     边界差 = 出场执行日当日的信号；
  3. R3 组合层另有 5 只持仓上限丢弃与不可交易剔除，证据版无组合层、不可交易信号
     仍开事件（钉死 e，1 例）。
- **实例对照（R3 §6.2 点名链）**：000333 同枢 ZG=68.97 链，R3 记"十二次原始发射
  仅一次存活（2025-12-15 / 12-23 / 2026-01-05 / 01-15 消失，终态仅 2026-01-29）"；
  本批标签流将该链锁为 5 个顺序事件（#2 2025-12-15 → #3 12-23 → #4 2026-01-05 →
  #5 01-15 → #6 01-29，全部 ZG=68.97，同枢再确认逐次解锁），其中 #6 与终态同日
  相容、#2~#5 为消失类——机械版视角的"重画"在证据版视角下是"5 个如实锁定的
  事件 + 4 个与终态矛盾的披露"。

  - 无任何结构信息票整行兜底 `{code} -`（如 688801）。

    `000333 三买结束(顶分型,确认2026-09-10)｜笔:下 分型:顶2日前 中枢:[84.44,88.10]下`
