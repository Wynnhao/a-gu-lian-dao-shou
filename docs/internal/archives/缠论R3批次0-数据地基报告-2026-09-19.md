## 4. open_qfq 构造 sanity

口径（§3.1）：open_qfq = open + (close_qfq − close)，逐 bar。

1. **构造恒等式**：open_qfq − close_qfq == open − close，全 32,926 行精确成立
   （加法偏移定义式，浮点零误差）。
2. **逐行抽查**（600519 / 002594 / 300308 各 3 行，覆盖除权前后）：
   - 600519 2024-08-22：open=1416.00, close=1410.05, close_qfq=1306.59 → open_qfq=1312.54 ✓
   - 002594 2024-03-20：open=217.01, close=218.48, close_qfq=70.11 → open_qfq=68.64 ✓
   - 300308 2025-07-23：open=179.00, close=186.18, close_qfq=184.78 → open_qfq=177.60 ✓
   （9/9 行 ok，完整清单见批次 0 运行日志）
3. **复核者注（诚实披露）**：验证过程中曾误用 |ret(open_qfq) − ret(open)| ≈ 0 作
   sanity 判据——常数加法偏移保**差分**不保**比值**，(o₁+k)/(o₀+k) ≠ o₁/o₀，非事件日
   该项 ~0.03% 量级的差异是加法复权的固有性质，不是数据缺陷。加法模型的真实保证是：
   分段常数偏移下 close_qfq 与 close 的日收益差在非事件日 ≈ k/p × ret（远小于 1pp），
   事件日才跃过 1pp 阈值——这正是 §3.1 畸变日判据能精确捕捉 129 处事件的原因（见 §2）。
4. 使用边界：结构引擎只用 native 的 high_qfq / low_qfq / close_qfq；open_qfq 仅用于
   入场/出场执行价，且 clean 窗（前 60 交易日无畸变）保证执行价不跨复权阶梯。
