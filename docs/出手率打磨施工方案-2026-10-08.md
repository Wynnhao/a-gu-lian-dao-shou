## 一、背景与根因（一段话）

9/14 以来 44 条决策仅 3 条 buy（出手率约 0.4 笔/周），出手窗口（9/16-9/22）内四道门叠加：拥挤熔断死区卡死 3 周（μ=0.012 落在滞回带 [0.005,0.015) 退不出，单票压 5%+conf 抬 0.7）× regime 避险档 0.2 帽（剩余预算仅 7.3%）× v2 打分结构性惩罚近期强势股（五因子全取反，热点截面 rank 必垫底）× 午评买入单被「非交易时段+下午不重提」结构性作废（9/21 美的 conf=0.72 唯一合格买点死于此）。叠加 watch 为死状态（无观察期机制，转化率 1/26，LLM 看不见 watch 历史）与 core51 硬边界（9 月唯一真实热点 CRO 全家在 extended 不可交易）。校准事实：9 月下旬 AI 组 -7.9%/半导体 -8.6%，没追是对的；watch 票次日均值 +0.64%/胜率 63.6%，选票眼光不差，缺的是出手通道。

### 批次5 · 热门池 top N 自动晋升【ADR 先行，最后施工】

新机制，最重，必须 ADR 定稿后再动手。设计要点（ADR 草案骨架，执行会话细化）：
1. **晋升条件**：hot_stock 连续 3 个交易日上榜，或 movers 强度≥档位阈值；且通过全套加票风控——复用 `signals/movers.py` 的 ST/退市/N·C 次新过滤 + `risk/blacklist.check_blacklist` + 腾讯核名。
2. **临时宇宙**：`dynamic_pool` 新增晋升状态字段（promoted_since）；decide 宇宙白名单 = core ∪ 晋升票；晋升容量上限 3 只。
3. **数据**：晋升时 fetcher 幂等回补该票日线（无历史数据的池外票先补数据再入宇宙——203 只历史池外票 daily_bar 零行的教训）。
4. **权限约束**：晋升票可 buy 但单票上限 0.10（比 core 的 0.15 更严）；规则 17/18/22 全链照常；人工 confirm 照常。
5. **退出**：连续 5 个交易日跌出热门/异动榜 → 自动降回 watch-only 并留痕；触止损/黑名单即除名；用户可手动移除。
6. **观测指标进日报**：晋升票的决策与盈亏单独列段，一个月后复盘决定去留。

**验收**：ADR 评审通过后分 5b(状态字段+风控核) → 5c(白名单+回补) → 5d(退出机制+日报) 三个子批落地；run_all 全绿 + 晋升/退出/风控拒三条合成用例。
**治理**：完整 ADR（新机制语义），本批次所有行为变更以 ADR 定稿为准。
