## 二、修复后回测实测（2026-09-13，口径修复后）

可成交口径 + 统一成本（佣金+印花+滑点10bps）下的双 profile 对比（同一 30 只票池，2024-01 起）：

| profile | 年化 | 最大回撤 | 达标(ann>基准 且 mdd>-25%) |
|---|---|---|---|
| momentum | +35.5% | -32.2% | 否（回撤超限） |
| reversal_lowvol | -8.0% | -36.2% | 否 |
| 沪深300 | +11.7% | — | — |
| reversal 滑点敏感性 | 5bps:-5.0% / 10bps:-8.0% / 15bps:-10.9% | | |

**解读（两个方向都要看）**：
- 旧回测 31.8% 年化是"30 只事后挑选的上涨票 + 未复权 + 涨停可成交 + 无滑点"合成的虚高；
  修掉后 momentum 也只有 +35.5% 且回撤 -32% 超验收线——旧数字不可信已被证实。
- reversal 在本票池表现差，与策略库"全市场短期反转显著"并不矛盾：票池本身是按
  "后来涨得好"人工挑的（幸存者偏差最利冲动量），反转因子在全市场有效 ≠ 在
  挑选后的高 beta 票池有效。
- **决策**：默认 profile 暂保留 reversal_lowvol（策略库研究先验 + P6 模拟盘本身就是
  为验证而设）；切换只需改 `config.json → signals.profile: "momentum"`。
  signal_eval 积累 100+ 样本后以实证 IC 定夺。
