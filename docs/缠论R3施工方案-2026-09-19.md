## 2. 范围与非目标

**做**：包含处理 → 分型 → 笔 → 笔中枢 → 三买（含"第一次创新高回踩"约束）入场；
出场 = 顶分型确认或固定 20 日先到者；因果实现 + 重画率度量；组合层 walk-forward
双腿回测（信号腿 vs 受控 momentum 基线腿）。

## 3. 预注册口径（批次 0 commit 后不可变；原文须完整抄入 signals/chan_research.py docstring）

### 3.1 数据
- 样本：config.json `watchlist_core`（51 只）；价格列 high_qfq / low_qfq / close_qfq；
  open_qfq = open + (close_qfq − close)（加法型复权当日全 OHLC 常数偏移，逐 bar 构造）。
- 畸变日：|ret_qfq − ret_raw| > 1pp 的交易日（单日复权阶梯）。
  clean 信号 = 确认日前 60 个交易日窗口内无畸变日（覆盖 EMA26 衰减 ~34 根）且形成窗无断链。
- 断链：按 trade_calendar，相邻 bar 间隔 >1 交易日即断链——不跨链连笔、不跨链比较。
- 每票 warmup 120 根有效 bar 后才允许产生信号；测试窗 2024-07-01 起。

### 3.2 结构定义（缠论机制员冻结清单）
- 包含处理：方向沿用前一合并K相对其前一根的方向（首根默认向下）；向上合并取
  max(高)/max(低)，向下取 min(高)/min(低)，递归至无包含。
- 分型：合并后相邻三根，中根高低点同为极值；端点=中根高低点；顶底分型不共用合并K。
- 成笔：主口径 = 严格笔（顶底分型间 ≥5 根合并K、不共用元素）；辅口径 = czsc 宽松笔
  （≥4 根）仅作敏感性披露，不参与 gate。
- 笔中枢：连续三笔重叠，ZG=min(三笔高点)、ZD=max(三笔低点)、须 ZG>ZD；后续笔与
  [ZD,ZG] 有重叠即延伸；不做中枢升级/扩展合并。
- 三买：中枢最后一个延伸笔之后的**第一根**向上笔笔顶 > ZG（突破），其后的**第一根**
  向下笔回抽，判据 = 回抽笔底分型端点价 > ZG（禁用收盘价替代）。
- 因果确认：三买确认日 = 回抽笔底分型第 3 根合并K收盘日；入场 = 确认日次日开盘价
  （open_qfq）；次日停牌顺延至复牌开盘。
- 出场：顶分型第 3 根合并K收盘确认 → 次日开盘出；或自入场起第 20 个交易日收盘出；
  先到者。成本：进/出各 0.15%（双边 0.3%）。
- MACD 顶背驰（close_qfq，EMA12/26、DEA9，柱面积同向前后笔段比较）：**只记录、不作
  主出场**，仅披露检出率与诊断。

### 3.3 组合构造
- 信号腿：三买确认次日开盘等权买入；持仓中同票重复信号忽略；同票 5 交易日内重复信号
  只取第一次；最大同时持仓 5 只，超额信号按确认时间先到先得、其余丢弃；
  **空仓期 = 现金**（主口径，写死；不持有 momentum 替代）。
- 基线腿（受控 momentum）：同一引擎、同一池、同持仓上限与成本；每月末换持
  "截至上月末 20 日动量最强 Top5"等权。**表述红线**：此为受控对照腿，非生产
  momentum profile，结题结论不得混称。

### 3.4 Gate（先定后跑，逐项过）
- **Gate 1 样本分辨率**：clean 信号 ≥80（同票 5 交易日去重后计）且信号月桶中位 ≥3；
  不足 → 判"无分辨率"直接 FAIL，不做超额归因。
- **Gate 2 因果性**：重画率 ≤15%。重画率 = 1 −（因果引擎实发信号中，最终结构下同票同
  确认日仍构成三买的比例）。
- **Gate 3 walk-forward**（对照基线腿，测试窗内净口径，三项全过）：
  ① 扣成本年化超额 ≥ +5%；
  ② 2025H1 / 2025H2 / 2026 三段超额 ≥2 段为正；
  ③ 信号腿 MDD 劣于基线 ≤2pp。
- 诊断（非 gate，如实披露）：事件层 fwd20 vs 池等权；MACD 背驰检出率；两种出场贡献
  拆分；分段收益。事件层 fwd20 对池等权 <+1% 时结题报告单列"入场几何增量薄"提示。

### 3.5 归档红线
- 任一 gate fail → 归档结题、不进生产；**禁止**改 ZG/中枢延伸/成笔口径/出场规则重跑；
  再评估须新预注册批次立项。脚本退出码 0=pass / 1=fail，供 CI 挂门。

## 3.6 口径钉死补遗（批次 0 裁决，冻结点前唯一一次）

> 性质：本节只做**消歧义**——把 §3 原文中可多种实现的语句钉死为唯一语义（"原文哪句 →
> 按什么语义实现"），不修改 §3 任何数字与规则，不新增可调参数。§3 原文一字不动；
> 批次 0 commit 后本节与 §3 同冻结。探针（/tmp/chan_probe_r3*.py）与本文语义冲突处，
> 一律以本节为准（探针实现不进仓库当口径）。

1. **月桶中位**（§3.4"信号月桶中位 ≥3"）：月桶 = 测试窗（2024-07-01 起）内全部自然月、
   **含零信号月**（信号为 0 的月计 0），对全部分月计数取中位数，≥3 判 PASS。理由：零信号月
   对 walk-forward 分辨率是实质信息，从严钉死。结题报告同时披露"仅覆盖月"口径作对照，但不参与 gate。
2. **畸变日 ret 计算**（§3.1"|ret_qfq − ret_raw| > 1pp"）：ret_raw = daily_bar.close 列的
   pct_change（按票内 bar 序），ret_qfq = close_qfq 列的 pct_change；**不使用 pct_chg 列**。
   首根 bar ret 为 NaN 不判畸变；判据为严格大于（=1pp 不算）。
3. **clean 规则"形成窗"**（§3.1"形成窗无断链"）：形成窗起点 = 该信号所属笔中枢**首笔的起点**
   ——即首笔起点分型极值所在合并K的首根原始 bar 的交易日；终点 = 确认日。窗内不得有断链段
   边界：若某复牌日（缺口后首根 bar 的交易日）r 满足 形成窗起点 < r ≤ 确认日，则该信号不 clean
   （复牌日恰为形成窗起点不算——结构整体位于断链后单段内，无跨链污染）。
   同一触发分型被多个枢命中时，形成窗取扫描序（笔序 i 最小）最先命中的枢。
   "确认日前 60 个交易日"按 trade_calendar 计，窗口 = 以确认日为末根、往前取 60 个交易日
   （**含确认日本身**；该日收盘是分型确认信息集的一部分，从严纳入）。
4. **包含处理**（§3.2"首根默认向下"）：首根合并K方向默认**向下**；处理第 2 根原始 bar 与首根
   合并K发生包含时（尚无"前一相对其前"可用）同样用该默认向下。探针实现默认向上，**以本条为准**。
   后续方向 = 前一合并K相对其前一根的方向，按合并K高点比较，**h 相等视为向上**。包含判定用
   闭区间（h/l 相等即包含），逐 bar 递归至无包含。分型判定用**严格不等**：中根高、低点须同时
   严格大于（顶）/严格小于（底）两侧合并K对应点，相等不成型。
5. **严格笔（主口径）**（§3.2"顶底分型间 ≥5 根合并K、不共用元素"）：顶/底分型**中间根合并K
   索引差 ≥4**（即两分型中间根间含 ≥5 根合并K，自动满足不共用）。相邻同型分型取更极端者、
   另一者丢弃（顶：后者 ≥ 前者取后者；底：后者 ≤ 前者取后者；**相等时取后到者**）；
   异性分型中间根索引差 <4 时丢弃**后者**（先到者优先）。处理为顺序贪心：每个新分型只与
   最近保留分型比较。与探针 build_strokes 惯例一致。
6. **中枢延伸与三买路径**（§3.2"后续笔与 [ZD,ZG] 有重叠即延伸"/"第一根向上笔笔顶>ZG"）：
   - 延伸判定 = 笔区间 [lo,hi] 与 [ZD,ZG] 有交集（闭区间：lo ≤ ZG 且 hi ≥ ZD）；
     **延伸笔数无上限**（探针的 ext≤3 上限是探针工件，不进口径）。
   - 中枢最后一个延伸笔之后，逐笔扫描：
     ① 下一笔为向下笔且与中枢无交集、hi < ZD（跌穿中枢下方）→ 中枢终结、无三买；
     ② 下一笔为向上笔且 lo > ZG（等价于"笔顶 > ZG 且不与中枢重叠"；闭区间下 lo = ZG 仍算
     交集、非突破）→ **突破笔**；
     ③ 向下笔与中枢无交集但整体高于中枢（lo > ZG）、或向上笔与中枢无交集且整体低于中枢
     （hi < ZD）——既非延伸亦非终结，按字面继续扫描（由笔的交替性，这两种情形的下一笔必
     分别落入②或①，扫描实际一步收敛）。
     与中枢有交集的向上笔（哪怕笔顶 > ZG）**是延伸、不是突破**——此即 §3.2"第一根"突破
     约束的实现语义。
   - 突破笔之后第一根向下笔为回抽笔（由笔交替性即紧邻下一笔；引擎按"其后第一根向下笔"
     字面语义实现，若迟迟无向下笔则继续等待）：回抽笔终点底分型端点价 > ZG → 三买成立，
     确认日 = 该底分型第 3 根合并K收盘日（该合并K最后一根原始 bar 的交易日）；
     回抽笔端点 ≤ ZG → **该中枢不产生三买**（单次尝试，不再从同枢重扫）。
7. **信号去重**（§3.3"同票 5 交易日内重复信号只取第一次"）：同票两信号确认日间隔（按该票
   实际有 bar 的交易日计数）<5 个交易日只取确认时间第一次；持仓中同票重复信号忽略（组合层）。
   去重属**信号生成层**，先于 clean 判定执行（先到者优先，与因果引擎一致）；Gate 1 的
   "clean 信号 ≥80（同票 5 交易日去重后计）"在该去重后集合上做 clean 判定并计数。
   多枢同触发分型按触发分型（合并K索引）去重，同探针。
8. **出场计数**（§3.2"自入场起第 20 个交易日收盘出"）：入场日 = D0（确认日次日开盘买入，
   停牌顺延至下一有 bar 交易日开盘）。顶分型出场：顶分型第 3 根合并K收盘确认 → 次一有 bar
   交易日开盘卖出。20 日出场：按该票实际有 bar 的交易日计数，入场日为第 1 根，第 20 根
   **收盘**卖出；两规则先到日期者生效，同日则按顶分型口径（开盘出）。停牌期间不计数、不交易，
   恢复后从停牌前状态继续。
9. **MACD 顶背驰（仅诊断）**（§3.2"柱面积同向前后笔段比较"）：close_qfq 上 EMA12/26、DEA9
   （标准递归定义），柱 = 2×(DIF−DEA)；对相邻同向笔段比较柱面积：向上笔比其前一向笔的
   红柱面积和、向下笔比其前一向下的绿柱面积绝对值和；后笔价格极值更极端而面积绝对值更小
   → 记背驰一次。**无阈值参数**，只统计检出率，不参与 gate 与出场。
10. **基线腿细节**（§3.3"每月末换持'截至上月末 20 日动量最强 Top5'"）：动量 = 截至上月末
    最后交易日 close_qfq 的 20 日收益（close_qfq[t]/close_qfq[t−20] − 1）；每月最后交易日
    收盘计算信号、次月首个有 bar 交易日开盘调仓；Top5 等权、每笔目标权重 20% 总资产；
    已持有票不重复计费（只对变动部分扣 0.15%/边）；池内 20 日历史不足的票剔除；
    不足 5 只时余下为现金。
11. **信号腿资金**（§3.3"等权买入"）：每笔目标权重 20% 总资产，按入场执行日开盘价（open_qfq）
    成交；不做 100 股取整（连续份额，研究口径）；现金不计收益；持仓盯市用当日 close_qfq，
    当日无 bar 沿用最近有 bar 收盘。
12. **反前视**：沿用 signals/backtest.py run_backtest 日循环的既有模式——每个交易日**先结算
    旧持仓当日收益并更新 NAV，再执行新调仓切权重**（该文件 L347-352：先按旧权重算 r 并
    复利、再做 rebalance 切 target）。信号腿确认日 → 次日开盘执行、基线月末信号 → 次月
    开盘执行，构造上无前视；引擎仍须遵守"先结算后切换"次序。
13. **Gate 3 MDD 差**（§3.4"③信号腿 MDD 劣于基线 ≤2pp"）：MDD 差 = 信号腿 MDD − 基线腿 MDD
    （日频 NAV、测试窗内、净口径），劣化 ≤2pp 即差值 ≤0.02。
14. **新增消歧（实现中发现，同样冻结）**：
    a. 分型确认时点 = 第 3 根合并K**最后一根原始 bar 的收盘**（conf = 该合并K的 i_end 所指 bar）；
       信号归属月 = 确认日所在自然月。

       结构引擎按断链切段、段内独立计算包含/分型/笔，不跨链连笔（§3.1 原文"不跨链连笔、
